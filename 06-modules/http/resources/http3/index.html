The same app, served over HTTP/2 and HTTP/3

A dual-stack server: your browser loaded this page over HTTP/2, then upgrades to HTTP/3 (QUIC) via Alt-Svc — exactly how h3 is deployed in production.

How the upgrade works. Browsers never speak h3 first. This page arrived over HTTP/2 on TCP; the server sent Alt-Svc: h3=":8444", so the API calls below move to HTTP/3 over QUIC. Accept the self-signed certificate once, then watch the badge (top-right) — or DevTools → Network → the Protocol column — flip to h3 (Chrome may need one reload).
